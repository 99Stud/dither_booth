Print settings are **device tuning**, one row in `print_config`, edited in the Darkroom. How to use them: [Tune the prints](/docs/venue/tune-prints/). The same row stores the **ticket orientation** (`upside_down`), which is not a print setting: it is set in admin's **Settings → Printing**, as **Bottom first** (on) or **Top first** (off).

| Field                  | Column              | Range      | Default           | Read by               |
| ---------------------- | ------------------- | ---------- | ----------------- | --------------------- |
| Dither mode            | `dither_mode_code`  | 0–10       | `10` (blue noise) | all                   |
| Exposure               | `exposure`          | > 0 – 4    | `1`               | all                   |
| Tone gamma             | `tone_gamma`        | 1 – 3      | `1.8`             | blue noise only       |
| Threshold              | `threshold`         | 0 – 255    | `128`             | all (final 1-bit cut) |
| Rotation               | `rotation`          | 0 – 360    | `0`               | all                   |
| Color scheme           | `color_scheme_code` | 0, 5, 6, 9 | `0` (Mono)        | error diffusion only  |
| Serpentine             | `serpentine`        | bool       | `true`            | error diffusion only  |
| Saturation             | `saturation`        | 0 – 4      | `1`               | error diffusion only  |
| Shadows lift           | `shadows`           | 0 – 1      | `0`               | error diffusion only  |
| Highlights compression | `highlights`        | 0 – 1      | `0`               | error diffusion only  |
| Ticket orientation     | `upside_down`       | bool       | `true`            | the printed tickets   |

Ranges are enforced twice: by the Darkroom's form schema and by CHECK constraints in SQLite.

## Dither mode codes

| Code | Mode                                                 |
| ---- | ---------------------------------------------------- |
| 10   | **Blue noise (macOS)** — engine's own ordered dither |
| 0    | None                                                 |
| 1    | Burkes                                               |
| 2    | Ordered                                              |
| 3    | Floyd-Steinberg                                      |
| 4    | Atkinson                                             |
| 5    | Stucki                                               |
| 6    | Sierra                                               |
| 7    | Sierra Lite                                          |
| 8    | Jarvis-Judice-Ninke                                  |
| 9    | Dizzy                                                |

Codes 0–9 are the error-diffusion and ordered modes of the dithering library. Code 10 is implemented in the engine (`image-manipulation/internal/ordered-dither.ts`).

## Color scheme codes

| Code | Palette      |
| ---- | ------------ |
| 0    | Mono         |
| 5    | Grayscale 4  |
| 6    | Grayscale 16 |
| 9    | Grayscale 8  |

The printer prints only black dots: grayscale palettes are reduced to 1-bit by the threshold after dithering.

## Pipeline

1. Rotate (white background), resize to **576 px** wide (no enlargement).
2. **Blue noise:** flatten on white, grayscale, apply a tone curve from exposure and tone gamma, threshold against a 64×64 void-and-cluster blue-noise mask (σ 1.5) anchored at the image origin. This reproduces how macOS prints to the TM-T20III: gray re-encoded at gamma 1.8, then halftoned.
   **Other modes:** the library's dither with exposure, saturation, shadows, highlights, serpentine and the palette.
3. Threshold to pure black/white.
4. Laid out by the receipt viewer, screenshotted, converted to a `GS v 0` raster. With the ticket orientation on **Bottom first** (`upside_down`), the 1-bit image is turned 180° first, for the photo receipt and the lottery ticket only; setup and Wi-Fi tickets always print top first. The Darkroom's receipt preview stays the right way up; dry-run PNGs show what the printer gets, so they come out turned.

The blue-noise mask is generated by `apps/engine/scripts/generate-blue-noise-mask.ts`; don't edit `blue-noise-mask.ts` by hand.
